# BrewDeck

[English version](README.MD)

Конструктор кастомной прошивки Nintendo Switch: Hekate, Atmosphère и выбранный homebrew, настроенные вплоть до отдельных ключей их конфигов.

BrewDeck — статическое веб-приложение. Оно проходит по консоли, софту и всем настройкам и на выходе даёт установщики для Linux и macOS (`install.sh`) и Windows (`install.ps1`) вместе с инструкцией по первому запуску. Установщик кладётся в корень SD-карты и собирает прошивку прямо там из последних релизов, так что в сборке ничего не упаковано заранее. Вся сборка хранится в адресе страницы: ссылка воспроизводит её целиком, кроме паролей и загруженных картинок. Софт перечислен там полностью, так что ссылка сохраняет сборку, даже когда меняется рекомендуемый набор. Интерфейс на английском, русском и украинском.

## Шаги

**Ревизия.** Erista, Mariko, OLED или Lite. От ревизии зависит, как стартует Hekate: из RCM или через чип, который загружает `payload.bin` из корня карты. А ещё какие инструменты имеют смысл и насколько можно разгонять. Консоль показана в натуральную величину, насколько браузер позволяет узнать плотность экрана.

**Версия HOS.** Все версии системы с релизом Atmosphère, в котором появилась их поддержка. Версия без поддержки в Atmosphère — ошибка, патчи, вышедшие раньше поддержки выбранной версии, — предупреждение.

**Софт.** Компоненты в восьми категориях:

- ядро: Atmosphère, Hekate, sys-patch;
- системные модули: MissionControl, sys-clk, SaltyNX, ldn_mitm, sys-con, SysDVR, sys-ftpd-light, sys-tune, Fizeau и другие;
- оверлеи: Tesla Menu или Ultrahand, Status Monitor, FPSLocker, ReverseNX-RT, оверлеи SysDVR и EdiZon, noled;
- homebrew: Homebrew App Store, DBI с переводами DBIPatcher на 20+ языков, Tinfoil, Goldleaf, AIO Switch Updater, JKSV, Checkpoint, EdiZon SE, NX Activity Log, emuiibo и другие;
- темы и главное меню: NXThemes Installer, Themezer, uLaunch;
- стриминг: Moonlight, Akira;
- эмуляторы: RetroArch, Flycast, PPSSPP, melonDS;
- разработка: sys-botbase, sys-gdbstub, Twili и другие.

Пресеты (Минимум, Рекомендуемый, Геймер, Эмуляция, Стриминг, Разработчик, Всё) заменяют выбор, компонент приносит с собой зависимости. Конфликты вроде Tesla Menu и Ultrahand, компоненты, бесполезные на ревизии, и заброшенные проекты объясняются, и тут же предлагаются исправления: конфликт решается удалением любой из сторон, недостающая зависимость — добавлением любой из альтернатив. Каждый компонент скачивается из Homebrew App Store или из релизов на GitHub, откуда свежее. Пакеты App Store регистрируются как установленные, так что магазин на консоли продолжает их обновлять.

**Запуск.** Пункты меню Launch в Hekate. Режимы загрузки: CFW на emuMMC, CFW на системной NAND и оригинальная прошивка. Другие emuMMC загружаются своими пунктами по папке (`emupath`), например SD01 или RAW1. Любой пункт, загружающий систему, может переопределить для себя ключи Exosphère: маскировку PRODINFO (`cal0blank`), USB 3.0 (`usb3force`) и режим памяти из boot config (`memmode`). Пэйлоады: Fusée, Lockpick RCM, TegraExplorer, CommonProblemResolver, тулбоксы HWFLY и Picofly, каждый своим пунктом. Автозагрузка выбирает любой из них или оставляет меню, тут же задаются задержка экрана загрузки и её отсчёт.

**CFW.** Настройки Hekate, Nyx и Atmosphère. Каждая — реальный ключ их конфигов со значением по умолчанию от разработчиков:

- Hekate: подсветка, выключение при пробуждении по RTC, nogc, Hekate как пэйлоад перезагрузки, защита папки bootloader;
- Nyx: цвета темы, домашний экран, проверка бэкапов, запись в eMMC по USB, Joy-Con, частота BPMP;
- Atmosphère: отчёты об ошибках, USB 3.0, читы, перезагрузка после сбоя, логи, сохранения на SD-карте, память апплетов;
- загрузчик homebrew: Альбом или любая игра с зажатой кнопкой, кнопки запуска игры без модов и читов.

**Безопасность.** Что консоль сообщает Nintendo и что разрешает монитор безопасности: блокировка серверов Nintendo через DNS-MITM на emuMMC, sysMMC или обоих, а в Exosphère маскировка PRODINFO, запись PRODINFO на sysMMC, отладочные режимы, режим памяти и лог UART.

**Плагины.** Настройки выбранных системных модулей и оверлеев: сочетание Tesla и Ultrahand, где sys-patch применяет патчи, вибрация, гироскоп и подсветка DualSense и DualShock в MissionControl, раскладки Status Monitor, логин, порт и сочетание паузы sys-ftpd, язык перевода DBI. Эти конфиги записываются, только если что-то изменено, так что обновление не затирает настроенное на консоли.

**Разгон.** Профили sys-clk по Title ID: шаблон (Штатно, Баланс, Производительность, Экономия батареи) или частоты CPU, GPU и RAM для каждого режима — в доке, в портативе и на зарядке. Частоты выше ограничений, которые sys-clk накладывает на ревизии, отмечаются.

**Оформление.** Экран загрузки, фон Nyx и иконки пунктов меню Launch из галереи картинок Hekate и Atmosphère и иконок Николь Маттеры или свои. Экран загрузки и фон видно на экране выбранной консоли в натуральную величину, так, как их нарисуют Hekate и Nyx. Любой пункт, включая пэйлоады, может взять свою иконку и свой экран загрузки (`logopath`), который Hekate показывает, когда автозагрузка запускает этот пункт. Картинки конвертируются в тот BMP, который ждёт Hekate, и встраиваются в установщики. Ещё картинки — по ссылкам на треды GBAtemp, где ими делятся.

**Сборка.** Проблемы всех шагов с исправлениями, установщики, инструкция и каждый сгенерированный файл с подсветкой синтаксиса — всё можно прочитать до запуска.

## Установка

1. Отформатировать SD-карту в FAT32.
2. Положить `install.sh` или `install.ps1` в корень карты и запустить его там:

   ```sh
   bash install.sh
   ```

   ```powershell
   powershell -ExecutionPolicy Bypass -File install.ps1
   ```

3. Загрузить консоль по инструкции из сборки.

Файлы с совпадающими именами перезаписываются, остальное на карте остаётся. Установщику нужны `curl` и `unzip`, `bsdtar` или `python3` на Linux и macOS, PowerShell 5.1 или новее на Windows. GitHub разрешает 60 анонимных запросов к API в час, `GITHUB_TOKEN` снимает это ограничение. Ключи, прошивки и игры не скачиваются.

## Разработка

```sh
npm install
npm run dev       # сервер разработки
npm run build     # статический сайт в dist/
npm test          # юнит-тесты, установщики запускаются, где есть bash, pwsh и shellcheck
npm run test:ui   # все шаги в headless Chrome
npm run sync      # версии, размеры, источники и логотипы каталога
```

Каталог лежит в `data/`, шаблоны сгенерированных файлов — в `templates/`, логотипы, фото и галерея — в `public/`.
